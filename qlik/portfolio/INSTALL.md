# Installation

## Required files

- `Libstar Retail and Manufacturing Intelligence.qvf`
- `extension/libstar-command-intelligence/`

## Windows paths

Copy the QVF to:

`C:\Users\<you>\Documents\Qlik\Sense\Apps\`

Copy the extension folder to:

`C:\Users\<you>\Documents\Qlik\Sense\Extensions\`

Restart Qlik Sense Desktop if the extension was copied while Qlik was already running. The app is self-contained and does not need a reload to display the included snapshot.
